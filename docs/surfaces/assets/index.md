# Assets

Assets contains the reference data used across Markets workflows. The application opens this area
on **Master List** by default.

## Reference Data

- [Asset Categories](reference-data/asset-categories.md) maintains the taxonomy used to group
  assets.
- [Master List](reference-data/master-list.md) is the canonical asset registry.
- [Indices](reference-data/indices.md) covers index definitions, formulas, and datasets.
