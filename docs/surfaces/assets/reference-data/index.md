# Reference Data

**Location:** Assets → Reference Data

Reference Data separates three related concepts that should not be confused:

- An **Asset** is one stable market identity.
- An **Asset Category** is a named collection whose membership can contain many Assets, while one
  Asset can belong to many categories.
- An **Index** is a reusable market observable with its own calculation and dataset lifecycle. It
  does not become an Asset merely because a portfolio or price workflow uses it.

Use the destination that owns the change you intend to make:

- [Asset Categories](asset-categories.md) for business or operational groupings.
- [Master List](master-list.md) to find and inspect canonical Asset identities.
- [Indices](indices.md) to create or inspect observable identities, formula versions, and canonical
  datasets.
