# Virtual Funds

**Location:** Managed Accounts → Account Management → Virtual Funds

Virtual Funds shows how a managed account is partitioned into allocation units associated with
target portfolios.

## What the list shows

The list shows the virtual-fund identifier, source account, target portfolio, and UID. Search is
available.

## Detail view

- **Overview** shows the complete virtual-fund identity.
- **Summary** explains its account and portfolio relationships.
- **Holdings** shows the latest holdings assigned to the fund.

This is an inspection surface. It does not create, edit, or delete virtual funds, and it does not
change allocation policy.
