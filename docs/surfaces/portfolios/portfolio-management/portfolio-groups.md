# Portfolio Groups

**Location:** Portfolios → Portfolio Management → Portfolio Groups

Portfolio Groups organizes portfolios into stable, reusable collections without changing the
portfolio identities themselves.

## What the list shows

The list shows group name, unique identifier, description, and UID. Search is available.

## Detail view

The **Portfolios** tab lists group members. Selecting an activated portfolio row opens that
portfolio's detail view.

## Available actions

- **Create group** creates or upserts a named group.
- **Edit group** changes mutable display and metadata fields.
- **Add portfolio** associates a portfolio by UID or unique identifier.
- **Delete group** removes the group.

Adding a portfolio changes group membership; it does not copy or modify the portfolio. Deletion is
permanent from the site.
