# Signals

**Location:** Portfolios → Portfolio Management → Signals

Signals maintains the metadata used to identify portfolio signals and provides a controlled way to
remove values generated for a signal.

## What the list shows

The list shows the signal description, signal UID, and metadata UID. Search is available.

## Available actions

- **Create signal** registers signal metadata.
- **Edit description** changes the human-readable description.
- **Delete weights** removes values generated for the selected signal.
- **Delete signal** removes the signal metadata and associated signal records.

Deleting weights and deleting the signal are different operations. Use **Delete weights** only when
the identity should remain available for regeneration. Use **Delete signal** only when the signal
itself should be removed.
