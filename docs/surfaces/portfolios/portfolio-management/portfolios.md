# Portfolios

**Location:** Portfolios → Portfolio Management → Portfolios

Portfolios is the canonical view of target portfolios and their calculated data. Use it to inspect
the portfolio identity and follow its links to calendars, published indices, and signals.

## What the list shows

The list shows the portfolio identifier, calendar, published index, signal, and UID. Search is
available.

## Detail view

- **Overview** shows the complete portfolio identity.
- **Summary** presents the canonical portfolio summary.
- **Weights** shows persisted portfolio weights.
- **Signal weights** shows weights generated by the linked signal.
- **Portfolio values** shows the portfolio value frame.

## Available actions

- **Delete weights** permanently removes the portfolio's persisted weights.
- **Delete portfolio** removes the portfolio identity when it is not protected by downstream
  references.

This surface does not create or edit portfolio identities. Treat both available actions as
destructive and confirm the selected portfolio before submitting them.
