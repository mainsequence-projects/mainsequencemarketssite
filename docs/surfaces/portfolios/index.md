# Portfolios

Portfolios brings together portfolio definitions, reusable groups, and signal metadata. The
application opens this area on **Portfolios** by default.

## Portfolio Management

- [Portfolios](portfolio-management/portfolios.md) shows portfolio identity, weights, signals, and
  values.
- [Portfolio Groups](portfolio-management/portfolio-groups.md) organizes portfolios into reusable
  collections.
- [Signals](portfolio-management/signals.md) maintains portfolio signal metadata and generated
  weights.
