# Pricing

Pricing contains curve definitions and the governed market-data configuration used to resolve
pricing inputs. The application opens this area on **Curves** by default.

## Pricing Data

- [Curves](pricing-data/curves.md) exposes curve identity, status, selections, and discount-curve
  resolution.
- [Market Data](pricing-data/market-data.md) manages named market-data sets and their concept
  bindings.
